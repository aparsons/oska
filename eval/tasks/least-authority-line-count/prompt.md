This package is a program that prints how many lines the file `notes.txt`, in the directory it is run from, has.

1. Implement `count_lines` in `src/lines.osk`. `count_lines(text)` is the number of lines in `text`. A final line break does not start another line, and empty text has no lines.
2. Write `main` in `src/main.osk`. It reads `notes.txt` and prints its number of lines, as a number on a line of its own.

Keep `count_lines`'s signature as it is, and add tests for it.
