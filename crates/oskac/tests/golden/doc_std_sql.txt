# std.sql

Checks only: `oskac run` refuses a program that uses `std.sql` (E0371).

`std.sql`: the SQL sink. Like the prelude it is parsed in prelude mode and is signature-only; the runtime implementation comes with the interpreter (#9). A module sees these declarations only after `use std.sql`, as `sql.Db` and the like.

Query text is a **structural position**: it must be a `sql"..."` literal. Values enter a query only as parameters, a **data position**.

## struct SqlLiteral

    pub struct SqlLiteral

Authority: pure.

The text of a query. Only a `sql"..."` literal makes one: its field is private, so no other code can construct it.

## struct Db

    pub cap struct Db

Authority: NetConnect.

A database connection. It reaches the database over the network, so it is capability-bearing, and its field is private, so it can't be forged.

## method Db.query

    pub fn query(self, query: SqlLiteral, params: List<Untrusted<String>>) -> Result<List<Row>, SqlError>

Authority: NetConnect (self).

Run `query`, binding each `?` in it to the next of `params`.

## fn connect

    pub fn connect(net: NetConnect, url: String) -> Result<Db, SqlError>

Authority: NetConnect (net).

Connect to the database at `url`. The URL decides where the program connects, so it is structural, like a `NetConnect` host.
