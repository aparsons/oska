# Contributing to Oska

Thank you for helping. Read `CODING_STANDARDS.md` before you change code, and run `scripts/check.sh` before you commit; it is the whole CI test job.

## Inbound license

Oska is licensed under the Apache License, Version 2.0 (see [LICENSE](LICENSE)). Under section 5 of that license, any contribution you intentionally submit for inclusion in Oska is licensed under the same terms, with no additional terms or conditions, unless you state otherwise in writing. By opening a pull request you agree to this.

Keep the [NOTICE](NOTICE) file as it is: section 4 of the license requires redistributions to carry it.

## Reporting a vulnerability

Do not open a public issue or pull request for a vulnerability. Follow [SECURITY.md](SECURITY.md) and report it privately.

## Issues and pull requests

Issues are tracked in GitHub Issues. Open a pull request against `main`; CI must pass before it merges.
