# Error codes

Every diagnostic code Oska reports, with a program that fails with it and the same program fixed. `oskac explain <code>` prints an entry offline.

All of them are in [codes.json](https://oskalang.dev/codes.json) as data.

- [E0200](https://oskalang.dev/codes/E0200.md): Unknown name "x" with a \\ in it, as in `Strng`
- [E0201](https://oskalang.dev/codes/E0201.md): A trait <script>alert(1)</script> where a type is expected
- [E0140](https://oskalang.dev/codes/E0140.md): An or-pattern such as `A | B`
- [P0004](https://oskalang.dev/codes/P0004.md): Division by zero, see [Tests](runtime.md#tests)
