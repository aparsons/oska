Error codes

Every diagnostic code Oska reports, with a program that fails with it and the same program fixed. oskac explain <code> prints an entry offline.

All of them are in codes.json as data.

  • E0200: Unknown name "x" with a \ in it, as in Strng
  • E0201: A trait <script>alert(1)</script> where a type is expected
  • E0140: An or-pattern such as A | B
  • P0004: Division by zero, see Tests
