# E0201

A trait <script>alert(1)</script> where a type is expected. Then more.

**Machine-applicable fix:** none.

## Example

This program fails with `E0201`.

```oska
fn show(x: Display) {
    let note = "<b>\"quoted\"</b>"
}

```
