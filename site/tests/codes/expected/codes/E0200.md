# E0200

Unknown name "x" with a \\ in it, as in `Strng`. See [the tour](/checker.md#tour).

**Machine-applicable fix:** Replace the name with the closest one.

## Example

This program fails with `E0200`.

```oska
fn f(x: Strng) {}
```

## Fixed

The same program, fixed.

```oska
fn f(x: String) {}
```

Listed in the [checker notes](/checker.md#e0200). `oskac explain E0200` prints this entry offline.
