E0200

Unknown name "x" with a \ in it, as in Strng. See the tour.

Machine-applicable fix: Replace the name with the closest one.

Example

This program fails with E0200.

fn f(x: Strng) {}

Fixed

The same program, fixed.

fn f(x: String) {}

Listed in the checker notes. oskac explain E0200 prints this entry offline.
