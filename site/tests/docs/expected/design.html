Oska design notes

Decisions are in adr/, terms in GLOSSARY.md, and the background in the research.

Principles

  1. Secure by default. The safe path is the shortest.
  2. No ambient authority. See ADR 0002.
  3. Legible. A snake_case_name stays as it is, and so does 2 * 3 * 4.

Capabilities

  • Fs attenuates:
    • to FsRead or FsWrite
    • to one directory, with restrict_to

  • Confinement. A restricted filesystem resolves every path:

    1. An empty path is refused.
    2. The path is canonicalized.

    Residual risk. A race remains, as Untrusted data explains.

  • A code block in an item:

    fn main(fs: FsRead) {
    let docs = fs.restrict_to("docs")
}
  1. A list that starts at three
  2. keeps its number.
