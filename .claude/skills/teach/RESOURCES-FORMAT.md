# RESOURCES.md format

Read this file when you add, remove, or check a source in `RESOURCES.md`.

`RESOURCES.md` lists the sources that the workspace trusts. Lessons take their facts from these sources.

## Rules

- Add only high-trust sources: primary sources, standard references, and recognised experts. A source that you cannot check is not high-trust.
- Give each entry a one-line note: what it is good for.
- Keep a **Gaps** section for the subjects that have no good source yet.
- Prune. Remove a source when a better one replaces it, or when it is wrong.
- Record the user's preferences about communities. If the user does not want communities, write that down.

## Sections

1. **Knowledge**: books, papers, official docs, and reference sites.
2. **Wisdom**: communities of practice, where people who do the work talk about it.
3. **Gaps**: subjects that need a source.

## Example

```markdown
# Resources: weekday sourdough

## Knowledge

- *Flour Water Salt Yeast* (Ken Forkish): timings and temperatures for home ovens.
- King Arthur Baking, "Sourdough starter" guide: how to feed and keep a starter.
- *Modernist Bread*, vol. 2: the science of fermentation, for the "why" questions.

## Wisdom

- A local bakers' club that meets each month: hands-on feedback on crumb.
- User preference: no online forums.

## Gaps

- A good source on whole-rye ratios for a weak starter.
```
