# GLOSSARY.md format

Read this file when you add or change a term in `GLOSSARY.md`.

The glossary holds the terms of this workspace. All lessons use these terms once the glossary exists.

## Rules

- Add a term only after the user can use it correctly. Do not add a term only because a lesson mentioned it.
- Use one word for one concept. List the other words that people use, under "Avoid".
- Keep each definition tight: one or two sentences.
- Use other glossary terms inside a definition, and link them.
- If the field uses a term in more than one way, say so. State which meaning this workspace uses.
- Change a definition when the user's understanding grows.

## Entry format

```markdown
## <Term>

<Definition in one or two sentences.>

Avoid: <other words for the same concept>.
Note: <an ambiguity in the field, if there is one>.
```

## Example

```markdown
## Levain

A small batch of [starter](#starter) that you feed for one bake and use all of in the dough.

Avoid: "leaven", "pre-ferment" (wider meaning).
Note: some books use "levain" for the starter itself. This workspace does not.

## Bulk fermentation

The rise of the whole dough after mixing and before shaping.

Avoid: "first rise", "bulk proof".
```
